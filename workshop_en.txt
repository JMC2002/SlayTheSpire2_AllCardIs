[h1] All Cards Become the Same Card (AllCardIs) [/h1]
[h2] 1. Overview [/h2]
Want to try turning every card into Claw? Want to turn every card into Snake Bite? Use this MOD to experience it!

[url=https://github.com/JMC2002/SlayTheSpire2_AllCardIs] GitHub Repository [/url]
[url=https://www.bilibili.com/video/BV1oMQcB4EJS] Demo Video (Bilibili) (All cards become Claw) [/url]

[h2] 2. Features [/h2]
[list]
    [*] Turns all cards (optionally attacks, skills, curses, powers, and event cards) into a specific card. In the settings screen, enter the card ID, CARD.xxx, or the card name in the current game language (such as "Claw" in the English UI). If a card name is duplicated (such as "Strike"), use the explicit ID instead. If you do not know the ID, you can look it up on the [url=https://sts2.huijiwiki.com/wiki] Wiki [/url]
    [img]https://images.steamusercontent.com/ugc/16571698319500396574/11E348516433B615DB63B17AF97D0AAD9C7FF748/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
    [*] When you want to disable this MOD, simply turn it off in the settings. There is no need to restart the game or unsubscribe
[/list]

[h2] 3. Notes [/h2]
[list]
    [*] Because of the game's mechanics, installing any MOD for the first time can cause save desynchronization. You can use [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3747533700] BetterSaveSlots [/url] to solve this
    [*] This MOD requires the following dependency:  
• [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3747526103] JmcModLib [/url]  
    [*] The localization content of this MOD (including the workshop page and changelog), except Chinese, is generated by ChatGPT. It currently supports all languages officially supported by the game. If you think any wording is inaccurate or would like to contribute your own translation, feel free to open an issue / PR on GitHub or contact me directly
[/list]

[h2] 4. Compatibility [/h2]
[list]
    [*] Since the game is still in EA, this MOD may stop working after game updates
[/list]
